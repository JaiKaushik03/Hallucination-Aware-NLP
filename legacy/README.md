# Archived, unverified original artifacts

These are the supplied project's historical README and workbook. They are retained unchanged for provenance, not presented as results of the corrected code.

The workbook contains 200 prediction rows. Stored exact accuracies are 0%, 29%, and 40.5%; the historical README incorrectly labels inclusive accuracies of 10.5%, 38.5%, and 51% as exact match. Both aware-system rejection columns contain zero rejections. The historical README claims 28% and roughly 10%.

`audit.json` is a re-score of these historical predictions using corrected answer metrics. It does not establish their model versions, prompts, sampling state, or provenance. No hallucination labels or valid hallucination-rate calculation are available. Read the current top-level README for the corrected experiment.
